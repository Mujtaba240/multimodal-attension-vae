# Notebooks

1. `00_colab_launcher.ipynb` — Environment setup (run first every session)
2. `01_setup_and_data.ipynb` — Download CelebA, verify dataloader
3. `02_image_vae.ipynb` — Train unimodal image VAE
4. `03_attr_vae.ipynb` — Train unimodal attribute VAE
5. `04_mvae_poe.ipynb` — Train MVAE (Product of Experts)
6. `05_mmvae_moe.ipynb` — Train MMVAE (Mixture of Experts)
7. `06_attn_fuse.ipynb` — Train Attention-Based Fusion model
8. `07_evaluation.ipynb` — Quantitative evaluation across all models
9. `08_geometric_analysis.ipynb` — Latent space geometry analysis
